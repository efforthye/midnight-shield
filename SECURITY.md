# Security policy

## Reporting a vulnerability in Midnight Shield

If you find a way to make Midnight Shield miss a vulnerability it should catch, or a security issue in the tool itself, please report it privately through [GitHub security advisories](https://github.com/efforthye/midnight-shield/security/advisories/new) instead of opening a public issue.

## Scope

Midnight Shield is a static analyzer. It reduces risk but does not prove a contract is secure. A clean scan is not an audit. Contracts that hold real value should also be reviewed by people who know Midnight and zero-knowledge circuits.

To report a vulnerability in Midnight itself (the node, ledger, compiler, or SDK), follow the security policy of the relevant repository under [midnightntwrk](https://github.com/midnightntwrk) instead.
