# MS015 unused-witness

**Severity:** info · **Confidence:** high · **Applies to:** Compact

## What it finds

A witness that no circuit calls.

When the witness looks like a membership proof (it returns a `MerkleTreePath`, or a vector of hashes named like a proof or a path), the finding is **medium**: either the action it was meant to guard skips the check, or that action was never written. Found in a payroll contract whose claim circuit never checks the payee proof, so any secret can claim.

## Why it matters

Usually harmless, but often a sign that a check was planned and never written: a witness for a Merkle path or a randomness value that nothing uses.

## Example

```compact
witness memberPath(): MerkleTreePath<10, Bytes<32>>; // never called
```

## Fix

```compact
Remove it, or call it where the check belongs.
```

## Not flagged / known limits

Files that use `include` (declarations may be used by the including file).
