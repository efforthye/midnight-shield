# MS115 hardcoded-password

**Severity:** high · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A password or passphrase written as a string literal: `password = "…"`, `passphrase: "…"`, or `privateStoragePasswordProvider: () => "…"`.

## Why it matters

Anyone with the code or the web bundle has it. When it protects Midnight's private state store, every user's private state is encrypted with the same public password.

## Example

```ts
privateStoragePasswordProvider: () => "Wallet-Pass-2026!"
```

## Fix

```ts
privateStoragePasswordProvider: () => askUserForPassword()
```

## Not flagged / known limits

- Passwords the code labels as throwaway (a literal or name containing test, local, dev, devnet, demo, example, sample, dummy, fixture), as the official examples do for local runs.
- Literals shorter than 4 characters, and names such as `passwordLabel`, `passwordMinLength`.
