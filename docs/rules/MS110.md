# MS110 secret-in-error

**Severity:** medium · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret inside `new Error(…)` (directly or in a template).

## Why it matters

Errors go to logs, crash reporters and error trackers, and are often shown to users.

## Example

```ts
throw new Error(`invalid seed ${seed}`);
```

## Fix

```ts
throw new Error(`invalid seed: expected 64 hex characters`);
```

## Not flagged / known limits

Names of secrets (`seedEnv`, `seedPath`), properties such as `seed.length`, and values passed through a function first.
