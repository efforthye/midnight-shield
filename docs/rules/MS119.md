# MS119 secret-in-public-env

**Severity:** critical · **Confidence:** high · **Applies to:** TypeScript / JavaScript

## What it finds

An environment variable with a prefix that the bundler copies into browser code (`VITE_`, `NEXT_PUBLIC_`, `REACT_APP_`, `PUBLIC_`, `EXPO_PUBLIC_`, `NUXT_PUBLIC_`, `GATSBY_`) whose name says it holds a seed, private key, mnemonic, secret or password.

## Why it matters

The value is in the JavaScript sent to every visitor, so it is public.

## Example

```ts
const seed = import.meta.env.VITE_WALLET_SEED;
```

## Fix

```ts
Keep it on a server, or have each user provide their own.
```

## Not flagged / known limits

Names that say they are public (`…_PUBLIC_KEY`, `…_ADDRESS`, `…_URL`, `…_ID`).
