# MS024 constant-condition

**Severity:** medium · **Confidence:** high · **Applies to:** Compact

## What it finds

An `if` on a constant (`if (true)`, `if (false)`), or an `assert(false)` directly in a circuit body.

## Why it matters

One branch is dead code, or the circuit always fails. Typically a check switched off while debugging. Mapped from Slither's `boolean-cst` and Circomspect's constant branch condition.

## Example

```compact
if (false) { assert(round > 0, "no round"); }
```

## Fix

```compact
Write the real condition, or remove the code.
```

## Not flagged / known limits

`assert(false)` inside a branch is a deliberate rejection and is not flagged.
