# MS033 unsupported-language-version

**Severity:** low · **Confidence:** high · **Applies to:** Compact

## What it finds

A `pragma language_version` that only allows versions outside the range Midnight Shield is tested with (currently Compact language **0.16–0.28**, the range used by the official examples, OpenZeppelin Contracts for Compact and the real projects in the benchmark).

## Why it matters

Midnight Shield has its own parser. When the language adds syntax, the parser may skip or misread it until a new release supports it. Part of the file is then not analyzed, and a clean result does not mean the code was checked. This rule makes that visible instead of silent.

The CLI also prints a warning on stderr whenever a file targets an untested version (MS033) or a part of it could not be parsed (MS000).

## Fix

Check for a newer Midnight Shield release. If none supports the version yet, review the findings for that file knowing they may be incomplete, and report the unsupported syntax in an issue.

## Not flagged

- Open ranges that include a tested version (`>= 0.25.0`).
