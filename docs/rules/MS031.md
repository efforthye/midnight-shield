# MS031 field-arithmetic-overflow

**Severity:** high · **Confidence:** medium · **Applies to:** Compact

## What it finds

Arithmetic (`+`, `-`, `*`, `+=`, `-=`) written into a ledger field of type `Field`. Mapped from Circomspect's field-arithmetic checks.

## Why it matters

`Field` arithmetic wraps around modulo a large prime instead of failing. Subtracting more than a balance gives a huge positive number; `Uint<…>` arithmetic is checked.

## Example

```compact
export ledger reserve: Field;
reserve = reserve - disclose(amount);
```

## Fix

```compact
export ledger reserve: Uint<128>;
assert(reserve >= disclose(amount), "insufficient");
```

## Not flagged / known limits

Only ledger fields; Field arithmetic on locals that never reaches the ledger is not flagged.
