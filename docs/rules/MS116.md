# MS116 secret-rendered-in-ui

**Severity:** medium · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret rendered in JSX: `<p>{mnemonic}</p>`, or a `value`, `title` or `children` attribute.

## Why it matters

Screenshots, screen sharing, session-replay tools and browser extensions can capture what is on screen.

## Example

```tsx
return <p className="phrase">{mnemonic}</p>;
```

## Fix

```tsx
Show it only after the user presses Reveal, and exclude it from session replay.
```

## Not flagged / known limits

Values passed through a component prop under another name.
