# MS020 unguarded-mint

**Severity:** high · **Confidence:** medium · **Applies to:** Compact

## What it finds

An exported circuit that mints tokens (`mintShieldedToken`, `mintUnshieldedToken`, `mintToken`) with no check that could identify the caller.

## Why it matters

Anyone can mint any amount, which makes the token worthless unless it is a deliberate faucet.

## Example

```compact
export circuit mint(a: Uint<64>, to: UserAddress): [] { mintUnshieldedToken(pad(32, "app:token:"), disclose(a), right<ContractAddress, UserAddress>(disclose(to))); }
```

## Fix

```compact
Add a caller check (and a limit) before minting.
```

## Not flagged / known limits

Same guard rules as MS019. Deliberate faucets and test tokens are flagged too: suppress them with a reason.
