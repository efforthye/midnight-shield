# MS111 secret-written-to-file

**Severity:** medium · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret passed to `writeFile`, `writeFileSync`, `appendFile` or `createWriteStream`.

## Why it matters

Files end up in backups, Docker images and commits.

## Example

```ts
writeFileSync("wallet.json", seed);
```

## Fix

```ts
Encrypt it first, or use the OS keychain.
```

## Not flagged / known limits

Writes with an explicit `mode` (such as `0o600`), which shows the file is deliberately private.
