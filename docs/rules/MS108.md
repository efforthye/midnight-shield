# MS108 dynamic-code-execution

**Severity:** high · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

`eval(…)`, `new Function(…)`, or `setTimeout`/`setInterval` with a string.

## Why it matters

If any part of the string can come from outside, an attacker runs code in the DApp, next to the user's keys and private state.

## Example

```ts
return eval(script);
```

## Fix

```ts
Parse data with JSON.parse; ship code as modules.
```

## Not flagged / known limits

Methods named eval on other objects (`redis.eval`).
