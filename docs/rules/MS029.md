# MS029 no-effect-statement

**Severity:** low · **Confidence:** high · **Applies to:** Compact

## What it finds

A statement that computes a value and does nothing with it: a bare name, a member access, or a comparison. Mapped from Slither's `redundant-statements`.

## Why it matters

Usually an assert that lost its `assert(…)`, or an unfinished assignment.

## Example

```compact
disclose(r) == round;
```

## Fix

```compact
assert(disclose(r) == round, "wrong round");
```
