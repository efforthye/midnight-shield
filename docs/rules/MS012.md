# MS012 transient-hash-in-state

**Severity:** medium · **Confidence:** high · **Applies to:** Compact

## What it finds

A ledger write whose value comes from `transientHash` or `transientCommit`, directly or through a local constant.

## Why it matters

Midnight documents that transient hashes are not guaranteed to stay the same across upgrades and should not be used to derive state data. A value stored today may stop matching the value the contract computes after an upgrade, which can lock users out of their funds or registrations.

## Example

```compact
export circuit register(): [] {
  memberId = disclose(transientHash<Vector<2, Bytes<32>>>([pad(32, "app:id:"), secretKey()])); // MS012
}
```

## Fix

```compact
export circuit register(): [] {
  memberId = disclose(persistentHash<Vector<2, Bytes<32>>>([pad(32, "app:id:"), secretKey()]));
}
```

## Not flagged

- Transient hashes used only inside a circuit, for example compared in an `assert`.

Reference: [transientHash](https://docs.midnight.network/api-reference/compact-runtime/functions/transientHash) in the Midnight docs.
