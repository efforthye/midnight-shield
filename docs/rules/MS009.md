# MS009 unbound-merkle-path

**Severity:** high

## What it finds

A circuit that checks the root of a Merkle path (`tree.checkRoot(merkleTreePathRoot<n, T>(path))`) but never asserts what the path's leaf is (`path.leaf == ...`).

## Why it matters

A Merkle path only proves that *some* leaf is in the tree. Paths are built from public ledger data, so anyone can construct a valid path for someone else's leaf. Unless the circuit checks that the leaf is derived from the caller's own secret, any non-member can pass the membership check with a member's path.

## Example

```compact
export circuit claim(): [] {
  const path = memberPath();
  assert(members.checkRoot(disclose(merkleTreePathRoot<10, Bytes<32>>(path))), "not a member"); // MS009
  // ...
}
```

## Fix

Bind the leaf to a value only the caller can produce:

```compact
circuit memberLeaf(sk: Bytes<32>): Bytes<32> {
  return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:member:"), sk]);
}

export circuit claim(): [] {
  const path = memberPath();
  assert(disclose(path.leaf == memberLeaf(secretKey())), "not your path");
  assert(members.checkRoot(disclose(merkleTreePathRoot<10, Bytes<32>>(path))), "not a member");
  // ...
}
```

The [Midnight security best practices](https://docs.midnight.network/guides/security-best-practices) pair Merkle membership with this kind of path-binding assert.

## Not flagged

- Any assert in the same circuit (or a helper it calls) that compares `path.leaf`, before or after the root check, including inside an `if`.
- Roots stored in a variable first (`const root = merkleTreePathRoot(path); tree.checkRoot(root)`) are followed.
- A helper circuit that binds the leaf to its own parameter (`requireMember(sk)` with `assert(path.leaf == memberKey(sk))`): the caller decides what `sk` is, and is checked where it calls the helper.
- A root check that neither sits in an assert (directly or through a local) nor guards a state change: `isMember(path): Boolean` only answers a question. Used in an assert by another circuit, it is checked there.
