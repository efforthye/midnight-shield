# MS114 secret-in-url

**Severity:** high · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret put into `history.pushState/replaceState`, `location.hash/href/search`, `new URLSearchParams(…)` or `searchParams.set/append`.

## Why it matters

URLs are kept in browser history, synced across devices, sent in Referer headers and logged by servers and proxies.

## Example

```ts
history.pushState({}, "", `/restore?seed=${seed}`);
```

## Fix

```ts
Keep the secret in memory or the private state provider; put only a public identifier in the URL.
```

## Not flagged / known limits

Secrets are recognized by name.
