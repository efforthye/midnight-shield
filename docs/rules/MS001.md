# MS001 own-public-key-auth

**Severity:** critical

## What it finds

`ownPublicKey()` used to decide who may call a circuit: compared with `==` / `!=` to a stored or supplied key, or checked with `.member()` on a ledger set. This includes cases where the value is passed into a helper circuit that does the comparison.

## Why it matters

`ownPublicKey()` is not like `msg.sender`. It is supplied by the prover when the proof is built, and nothing in the proof binds it to the caller's wallet. The owner's key is usually public on the ledger, so anyone can supply it and pass the check.

## Example

```compact
export ledger owner: ZswapCoinPublicKey;

export circuit withdraw(): [] {
  assert(ownPublicKey() == owner, "not the owner"); // MS001
}
```

## Fix

Authorize by proving knowledge of a secret. Store a domain-separated hash of the secret, and recompute it from a witness:

```compact
witness secretKey(): Bytes<32>;
export ledger ownerId: Bytes<32>;

circuit deriveId(sk: Bytes<32>): Bytes<32> {
  return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:owner:"), sk]);
}

export circuit withdraw(): [] {
  assert(deriveId(secretKey()) == ownerId, "not the owner");
}
```

## Not flagged

- `ownPublicKey()` as a payment destination, e.g. `left<ZswapCoinPublicKey, ContractAddress>(ownPublicKey())`.
- Comparisons with a constant, such as checking for the zero key.
- `ownPublicKey()` hashed together with a secret before the comparison.
