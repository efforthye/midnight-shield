# MS016 unused-circuit

**Severity:** info · **Confidence:** high · **Applies to:** Compact

## What it finds

A circuit that is not exported and is never called or passed as a value.

## Why it matters

Dead code. Often a helper written for a check that was later forgotten.

## Example

```compact
circuit checkLimit(a: Uint<64>): Boolean { return a <= 100; } // never called
```

## Fix

```compact
Remove it, or call it.
```

## Not flagged / known limits

Files that use `include`; exported circuits (callable from outside).
