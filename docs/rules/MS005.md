# MS005 missing-domain-separation

**Severity:** low

## What it finds

A `persistentHash` / `transientHash` over private data where none of the inputs is a constant domain tag. When a helper circuit receives the tag as a parameter, the rule checks the callers in the same file before reporting.

## Why it matters

If the same secret is hashed for different purposes (a public key, a nullifier, a commitment) without a tag, the outputs can collide or be linked across uses and across contracts. A distinct tag per purpose keeps them independent.

## Example

```compact
witness secretKey(): Bytes<32>;
export ledger publicKey: Bytes<32>;

export circuit register(): [] {
  publicKey = disclose(persistentHash<Bytes<32>>(secretKey())); // MS005
}
```

## Fix

```compact
publicKey = disclose(persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:pk:"), secretKey()]));
```

## Known limits

Library helpers that receive their tag from another file cannot be checked, because Midnight Shield analyzes one file at a time. Suppress with `// shield-disable-next-line MS005` if the tag is supplied by the caller.
