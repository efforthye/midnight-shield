# MS117 secret-sent-to-analytics

**Severity:** high · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret passed to an analytics or error-tracking call: `Sentry.setContext/setExtra/setUser/captureException`, `posthog.capture`, `analytics.track`, `mixpanel.track`, `gtag(…)`, ….

## Why it matters

Those services store the data, and many people and vendors can read it.

## Example

```ts
Sentry.setContext("wallet", { seed });
```

## Fix

```ts
Sentry.setContext("wallet", { walletId: publicKeyOf(seed) });
```

## Not flagged / known limits

Secrets are recognized by name; a whole state object passed as is (`Sentry.setContext("s", state)`) is not inspected.
