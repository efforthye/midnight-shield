# MS017 tautological-assert

**Severity:** medium · **Confidence:** high · **Applies to:** Compact

## What it finds

An `assert` that can never fail: `assert(true)`, `x == x`, `x <= x`, or an unsigned value compared `>= 0`.

## Why it matters

The assert looks like a check but does nothing. It is often a typo for a real comparison (`> 0`, or a ledger value).

## Example

```compact
assert(disclose(amount) >= 0, "negative amount"); // Uint is never negative
```

## Fix

```compact
assert(disclose(amount) > 0, "zero amount");
```

## Not flagged / known limits

Signed types do not exist in Compact, so every `>= 0` on a number is always true.
