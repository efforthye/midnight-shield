# MS120 secret-from-public-data

**Severity:** high · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

A variable named like a secret (`voterSecret`, `secretKey`, `sk`, `seed`) declared with a value computed only from public values: a wallet address, a public key, an account id, a user name or an email, with no randomness, signature or other secret mixed in.

## Why it matters

Anyone who knows the public value can compute the same secret. In a Midnight DApp, that secret is usually what the contract trusts as the user's identity (hashed into a commitment, a Merkle leaf or a nullifier), so whoever recomputes it can act as that user: vote again, claim, or spend.

## Example

```ts
const voterSecret = await sha256(walletAddress);
```

## Fix

```ts
const voterSecret = crypto.getRandomValues(new Uint8Array(32)); // keep it in private state
```

Or derive it from a wallet signature, which only the key holder can produce.

## Not flagged / known limits

- Values that mix in a secret, a signature, a seed, a mnemonic or a random source (`hkdf(signature, address)`).
- Names that say the value is public or a hash (`secretHash`, `ownerPk`, `userId`).
- Only declarations with `const` or `let` in one statement; a secret assembled across several statements is not followed.
