# MS021 nullifier-matches-leaf

**Severity:** high · **Confidence:** medium · **Applies to:** Compact

## What it finds

A value added to a nullifier `Set` that is built from the same domain tag and the same inputs as a leaf added to a Merkle tree.

## Why it matters

The point of a Merkle tree is that a member's action cannot be linked to their leaf. If the nullifier equals the leaf, anyone can match them and see which member acted.

## Example

```compact
voters.insert(disclose(persistentHash<…>([pad(32, "app:voter:"), secretKey()])));
…
nullifiers.insert(disclose(persistentHash<…>([pad(32, "app:voter:"), secretKey()])));
```

## Fix

```compact
Use a different tag for nullifiers ("app:nullifier:").
```

## Not flagged / known limits

Hashes built in helper circuits are compared by their call, not followed inside.
