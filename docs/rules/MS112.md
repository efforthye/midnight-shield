# MS112 postmessage-wildcard

**Severity:** medium · **Confidence:** high · **Applies to:** TypeScript / JavaScript

## What it finds

`postMessage(data, "*")`.

## Why it matters

The message goes to whatever page is in the target window, including one an attacker navigated there.

## Example

```ts
window.parent.postMessage(state, "*");
```

## Fix

```ts
window.parent.postMessage(state, "https://app.example.com");
```
