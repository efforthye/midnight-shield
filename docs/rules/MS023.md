# MS023 secret-key-as-randomness

**Severity:** high · **Confidence:** medium · **Applies to:** Compact

## What it finds

A commitment whose randomness is a witness named like a long-term secret key (`secretKey()`, `sk()`).

## Why it matters

Opening the commitment reveals its randomness, which here is the key. And committing to the same value twice gives the same commitment, which links the user's actions.

## Example

```compact
c = disclose(persistentCommit<Uint<8>>(choice(), secretKey()));
```

## Fix

```compact
Use a fresh randomness witness for each commitment.
```

## Not flagged / known limits

Relies on the witness name.
