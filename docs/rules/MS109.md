# MS109 insecure-transport

**Severity:** medium · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

An `http://` or `ws://` URL to a remote host, in code about an indexer, node, RPC, GraphQL or pub-sub endpoint.

## Why it matters

Requests show which addresses and contracts a user follows, and answers can be changed in transit.

## Example

```ts
indexerUri: "http://indexer.example.com/api/v1/graphql"
```

## Fix

```ts
Use https:// and wss://.
```

## Not flagged / known limits

localhost, private network ranges, `.local`/`.internal` hosts, and the proof server (MS101).
