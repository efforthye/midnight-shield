# MS032 unused-local

**Severity:** info · **Confidence:** high · **Applies to:** Compact

## What it finds

A local constant that is never used. Mapped from Circomspect's unused-variable pass.

## Why it matters

Often the value a check was meant to compare (`assert(x == …)`), so its absence is a missing check.

## Example

```compact
const expected = persistentHash<…>(…);  // never used
```

## Fix

```compact
Use it in the check, or remove it.
```

## Not flagged / known limits

Names starting with `_` are skipped.
