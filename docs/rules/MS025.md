# MS025 write-after-write

**Severity:** medium · **Confidence:** high · **Applies to:** Compact

## What it finds

A ledger field assigned twice in a row in the same circuit, with no read of it in between. Mapped from Slither's `write-after-write`.

## Why it matters

The first write has no effect. One of the two was probably meant for a different field.

## Example

```compact
phase = 1;
phase = 2;
```

## Fix

```compact
Remove one, or point it at the right field.
```

## Not flagged / known limits

Only straight-line statements at the top of a circuit body; a branch or a call to another circuit ends the sequence.
