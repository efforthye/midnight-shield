# MS026 shadowed-builtin

**Severity:** low · **Confidence:** high · **Applies to:** Compact

## What it finds

A circuit, witness, parameter or local constant named like a standard-library function: `disclose`, `pad`, `persistentHash`, `assert`, …. Mapped from Slither's `shadowing-builtin`.

## Why it matters

Readers and AI agents assume the standard meaning; the code does something else.

## Example

```compact
export circuit echo(disclose: Uint<8>): Uint<8> { return disclose; }
```

## Fix

```compact
Rename it.
```
