# MS026 shadowed-builtin

**Severity:** low · **Confidence:** high · **Applies to:** Compact

## What it finds

A circuit, witness, parameter or local constant named like a standard-library circuit: `persistentHash`, `persistentCommit`, `transientHash`, `ownPublicKey`, `merkleTreePathRoot`, `left`, `right`, …. (`disclose`, `pad`, `assert` and `default` are keywords, so the compiler already rejects those.) Mapped from Slither's `shadowing-builtin`.

## Why it matters

Readers and AI agents assume the standard meaning; the code does something else.

## Example

```compact
export circuit echo(persistentHash: Bytes<32>): Bytes<32> { return disclose(persistentHash); }
```

## Fix

```compact
Rename it.
```
