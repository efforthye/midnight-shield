# MS028 locked-tokens

**Severity:** medium · **Confidence:** medium · **Applies to:** Compact

## What it finds

A contract that receives tokens (`receiveShielded`, `receiveUnshielded`, `receive`) and has no circuit that sends any. Mapped from Slither's `locked-ether`.

## Why it matters

Deposits can never leave the contract.

## Example

```compact
export circuit deposit(coin: ShieldedCoinInfo): [] { receiveShielded(disclose(coin)); }
```

## Fix

```compact
Add a guarded withdrawal circuit, or make sure locking is intended.
```

## Not flagged / known limits

Files that import other modules or use `include` (the send may be there).
