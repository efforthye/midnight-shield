# MS036 claimed-identity

**Severity:** critical (high when every transfer in the circuit goes to an address kept in the ledger) · **Confidence:** medium · **Applies to:** Compact

## What it finds

An access check that compares a stored owner or admin id with a parameter of the circuit:

```compact
assert(ownerId == disclose(callerId), "only the owner");
```

It is reported when the stored side reads the ledger, the other side is only parameters (directly, through `disclose()`, a cast or a local constant), and either the field is named like a role (owner, admin, operator, issuer, …) or the assert message talks about access ("only", "owner", "not authorized", …).

## Why it matters

Everything on the ledger is public. Anyone can read `ownerId` and pass the same value as `callerId`, so the check lets everyone through. It reads like an owner check, which is why it survives review. Found in third-party contracts, guarding admin settings.

When every transfer in the circuit goes to an address kept in the ledger (`depositor`, the contract itself), the check still lets anyone through, but the coins reach the intended party. The finding is then **high**, and says so: anyone can trigger the transfer, and settle the contract, at a moment of their choosing (for example, refund an escrow in the middle of a deal).

## Example

```compact
export ledger ownerId: Uint<32>;

export circuit setRate(callerId: Uint<32>, rate: Uint<64>): [] {
  assert(ownerId == disclose(callerId), "only owner");   // MS036
  feeRate = disclose(rate);
}
```

## Fix

Make the caller prove knowledge of a secret. Store a hash of it, and compare it with the same hash recomputed from a witness:

```compact
export ledger ownerId: Bytes<32>;
witness secretKey(): Bytes<32>;

circuit deriveId(sk: Bytes<32>): Bytes<32> {
  return persistentHash<Vector<2, Bytes<32>>>([pad(32, "myapp:owner:"), sk]);
}

export circuit setRate(rate: Uint<64>): [] {
  assert(deriveId(secretKey()) == ownerId, "only owner");
  feeRate = disclose(rate);
}
```

## Not flagged / known limits

- A parameter that is hashed before the comparison (`hash(password) == ownerHash`). Parameters of exported circuits are private inputs, so a hashed preimage works as a secret.
- Comparisons with no sign of being about access (`assert(round == disclose(r), "wrong round")`).
- Parameters of helper circuits: whatever the caller passes in is not known, so only the exported circuit's own parameters count.
- Circuits inside a `module`: the importing contract decides how they are called.
