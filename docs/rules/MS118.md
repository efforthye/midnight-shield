# MS118 unsafe-html

**Severity:** medium · **Confidence:** medium · **Applies to:** TypeScript / JavaScript

## What it finds

`innerHTML`/`outerHTML` assigned from a variable, `dangerouslySetInnerHTML`, `document.write(…)`, `insertAdjacentHTML(…)`.

## Why it matters

If any part comes from chain data, a URL or another user, it runs as script inside the DApp, which can read private state and ask the wallet to sign.

## Example

```ts
el.innerHTML = message;
```

## Fix

```ts
el.textContent = message; // or DOMPurify.sanitize(message)
```

## Not flagged / known limits

Assigning a plain string literal (`el.innerHTML = ""`).
