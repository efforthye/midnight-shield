# MS022 shadowed-ledger-field

**Severity:** low · **Confidence:** high · **Applies to:** Compact

## What it finds

A parameter or local constant with the same name as a ledger field.

## Why it matters

Inside the circuit, the name now means the local value. A read or write meant for the ledger silently uses the local one.

## Example

```compact
export ledger balance: Uint<64>;
export circuit deposit(balance: Uint<64>): [] { … }
```

## Fix

```compact
Rename the parameter (`amount`).
```
