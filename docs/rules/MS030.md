# MS030 bidi-control-character

**Severity:** high · **Confidence:** high · **Applies to:** Compact and TypeScript

## What it finds

Invisible bidirectional-control characters (U+202A–U+202E, U+2066–U+2069, U+200E, U+200F, U+061C) anywhere in the source.

## Why it matters

They reorder how text is displayed, so code can look different from what the compiler sees: a check that appears active can be inside a comment ("Trojan Source", CVE-2021-42574). Mapped from Slither's `rtlo`.

## Example

```
// is admin? \u202E } if (isAdmin) { \u2066
```

## Fix

```
Remove the characters.
```

## Not flagged / known limits

Ordinary right-to-left text (Arabic, Hebrew) without control characters is not flagged.
