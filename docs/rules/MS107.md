# MS107 tls-verification-disabled

**Severity:** high · **Confidence:** high · **Applies to:** TypeScript / JavaScript

## What it finds

`rejectUnauthorized: false`, `strictSSL: false`, or `NODE_TLS_REJECT_UNAUTHORIZED` set to `0`.

## Why it matters

Anyone on the network path can impersonate the indexer, node or wallet backend, read requests and feed the DApp false chain data.

## Example

```ts
new https.Agent({ rejectUnauthorized: false })
```

## Fix

```ts
new https.Agent({ ca: readFileSync("ca.pem") })
```
