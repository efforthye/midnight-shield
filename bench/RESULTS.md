# Benchmark results

Generated by `npm run bench -- --write`. 170 labeled files: 118 expected findings reported, 0 missed, 0 false positives.

The cases in [cases/](cases/) are written for this benchmark: for each rule, the plain vulnerable pattern, variants made to slip past it (aliases, helper circuits, structs, other names) and safe code that looks similar. [known/](known/) holds minimal reproductions of bugs found in public projects. Results on code written by others, without labels, are in the [field test](../verify/field-test.md).
